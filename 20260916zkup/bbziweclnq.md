# 16岁儿子走了，父亲决定捐献儿子的器官，理由值得杭州骄傲↓↓↓

> 更新时间：2026-09-16 (UTC+8)

16岁的大男孩龙龙走了。昨天上午，龙龙安静地仰面躺在浙江大学医学院附属第一医院重症监护室病房，盖着蓝色的条纹床单，一动不动。22岁的姐姐摸了摸他的脸，45岁的父亲握了握他的手臂，43岁的母亲捏了捏他的双脚。

随后，一家人手拉着手，绕着龙龙的床沿转了一圈，默哀了一分钟。在场的医护人员也不约而同地低下了头，这是他们与龙龙的告别。
悲伤中，龙龙的父亲做了一个决定——捐献儿子全部有用的器官，他说，杭州让他感受到了温暖，好心人很多，儿子生前也是个热心肠，很喜欢帮人，就当是他最后给杭州留下的东西吧。**早上还说下班吃妈妈买的肉包**晚上却突发猝死，再没醒来
“我早上出门的时候，他还好好的，让我下班给他带肉包吃，我还和他说，再给他烧碗西红柿蛋花汤喝。”这句话龙龙的妈妈重复了三遍。

“晚上5点40的样子，我回到家发现他不在，打给他。他说要加班，让我把包子给他留着，他回来吃。”龙龙妈说，“我给他买了6个肉包，西红柿蛋花汤想等他到家再给他做的，没想到……”

面对龙龙的意外，龙龙妈始终不敢相信，她说，龙龙长这么大，几乎没吃过药，可能连感冒是什么都不知道，车祸，或者其他的意外，她都能接受，唯独“病死”，她真的不敢相信。

直到看到躺在重症监护室的龙龙，她才哭花了眼睛，颤巍巍地拿出手机，打给了刚回老家办事的龙龙爸。

“我们家附近没有机场，最近的在西安，为了早点赶到机场，我直接打了个出租车，花了1350块钱，但还是没赶上7点多那班飞机。”龙龙爸搓了搓眼睛说，这是他四十多年来第一次坐飞机。

4月2日下午，当龙龙爸赶到医院时，等待他的是意识昏迷、毫无知觉的儿子，以及一张病危通知书和一些需要家属签字的告知书。

由于病情需要，龙龙被转到浙大一院进行救治。

“他来的时候情况非常重，整个人处于深昏迷状态，血压需要靠大剂量的升压药才能维持。”浙大一院重症监护室、浙江省人体器官捐献评估专家吴晓梁副主任医师说，**“经检查，我们初步考虑是心律失常引起的心脏骤停，即，心因性猝死。”**
**面对拮据的生活**一家人决定到杭州闯一闯
龙龙，身高172厘米，体重120斤，2000年8月11日出生，当年恰逢龙年，父母便给他取了这个名。姐姐说，他是个典型的狮子座男孩，阳光、热情、自信、大方，有时又有些调皮。

来杭州前，龙龙的父母靠种田为生，全家一年的总收入只有两千多，住的是瓦片房，冬天冷，夏天热，晴天还能住，碰上下雨天，就会出现屋外下大雨，屋内下小雨的情况。

“每次下大雨，一定要用锅碗瓢盆来接。”龙龙的姐姐说。

看着孩子慢慢长大，奶奶日益衰老，龙龙的父亲咬了咬牙，向亲戚朋友们共借了14万块钱来盖房子。

14万，对龙龙一家而言，这是个天文数字，怎么还？

2012年10月，经亲戚介绍，龙龙的父母和姐姐来到杭州打工。父亲初中没毕业，母亲小学毕业，姐姐初中毕业。“我们没文化，当地也没有熟人，只能在工厂里打打工。”龙龙爸说，“龙龙是第二年春天来的，因为，老家只剩一个70多岁的奶奶，照顾不了他，我们担心他学坏，就让他也过来了。”

打工的日子虽然辛苦，但龙龙一家却在苦中作乐，彼此鼓励。

和其他家人不同，由于龙龙不满18周岁，不能到厂里打工，在家闲了一段时间。看着家里的情况，龙龙决定先去学门手艺。

“他去学了电烙，开始，师傅嫌他年纪小不愿意收，但他不死心，每天缠着师傅，师傅不理他，他就站在旁边看，边看边学，师傅被他打动了。”龙龙妈说，“他就是这么一个固执的人，我们也知道他是想学门手艺，好分担家里的债。”

去年，年满16周岁的龙龙在家附近找了一份简单的工作。“工资不多，每个月只有六七百。一发工资，他就会交给我们，自己只留几十块钱，让我们拿去还债，我们让他自己留着花，买些自己想买的东西，他不肯。”龙龙妈说。

“去年我生日，我自己都忙到忘记了。没想到，他不但记得，还买了我爱吃鸡腿、鸡爪。”

经过几年的努力，龙龙一家的生活终于有了改善，到今年初，家里的债务差不多都还上了。（龙龙的QQ空间。姐姐说，有那么一段时间，他非常想回去读书，但家庭条件不允许，他偷偷地哭了。）
**龙龙捐献的器官救了6个人**让两个人重见光明
世界待他们残忍，他们却对世界温柔以待。

龙龙走后，龙龙爸做出了器官捐献的决定，他说，龙龙还这么小，还没给这个世界留下什么，没有奇迹能让他活过来，但只要想到儿子的身体的某些部分还在以某种方式“活着”，能帮上有需要的人，他就满足了。

吴晓梁医师说，经过评估，龙龙的一个心、一个肝、两个肺、两个肾，以及两个角膜都符合捐献的条件。

截至发稿，相关的移植手术仍在继续，一切顺利的话，龙龙捐献的器官可救6个人，让2个人重见光明。

据统计，龙龙是浙江省今年第56例器官捐献者，目前，我省器官捐献者已累计673例。
