# 中国地贫基因携带者高达3000万人，贝康医疗打造创新产品助力地贫防治

> 更新时间：2026-09-19 (UTC+8)

2023年5月8日是“世界地贫日”，这一天旨在提高人们对于地中海贫血症的认识和关注。今年的主题是“防控地贫，重在筛查”，倡导备孕夫妻积极参加地贫筛查，阻断地贫遗传。

近年来，随着创新技术的发展和进步、居民健康意识的不断提高以及国家政策层面的支持，地贫筛查市场不断扩大，相关企业推出的基因检测、生殖健康检测、孕前保健服务等产品和服务受到广泛关注，在市场上具有巨大发展空间。
**1、难治可防的地中海贫血**
地中海贫血简称地贫，又称海洋性贫血或珠蛋白生成障碍性贫血，是由于珠蛋白基因缺陷导致珠蛋白肤链合成障碍所致的遗传性溶血性疾病。其是一种常染色体隐形遗传性疾病，

由于症状的不同,地贫又可分为静止型、轻型、中间型和重型。

轻型、静止型：对健康不造成影响，基本无需治疗。

中型：会出现一定贫血、溶血、生长发育障碍等的症状，患者需要补充叶酸和维生素促进造血，必要时需进行输血治疗。这类患者即便经过治疗，其健康状况与正常人仍会存在差距。

重型：目前临床上对重型患者尚无经济有效的治疗手段，唯一可能实现根治效果的是造血干细胞移植，但它对医院技术要求高，加上配型难度很大，因此全国范围内仍无法普及。此外，部分重型患者在没出生前就因全身水肿而引起母体流产，或者出生数日即出现贫血、肝脾肿大进行性加重、黄疸等症状，并伴有发育不良，需要终身依赖输血，甚至难以活到成年。

由于中重型地贫患者需要定期输血和去铁治疗维持生命，每年的医药费用可高达10万余元。这也带给很多家庭沉重的经济负担，出现因病致贫、返贫的现象。《中国重型β—地中海贫血成人患者疾病经济负担报告》提到，中国有84%的重症地贫患者因为常年需要治疗，费用过高而中途放弃治疗。

相关数据显示，全世界每年有超过5万名地贫患儿出生，该遗传疾病多发于地中海沿岸、非洲和东南亚地区，具有明显的地域分布差异和种族特征。在我国中间型和重型地贫患者约有30万人，地贫基因携带者高达3000万人，其中长江以南地区为地贫的高发地区，尤以两广地区最为严重。其中广西地区地贫基因携带率高达24%;广东地区则高达11%。

据悉，地中海贫血遵循常染色体隐性遗传规律。即：如果父母双方一方是轻型地中海贫血，一方是正常的，其后代有50%的机会是正常的，另外50%的机会是轻型地中海贫血；如若父母双方都是轻型地中海贫血，他们的孩子有1/4的机会是正常的，1/4的机会是中度地中海贫血，还有1/2的机会是轻度地中海贫血。

因此通过人群筛查和产前诊断阻止患儿出生是首选预防措施，为了避免地贫基因携带者与地贫患者结婚，可以采取基因测序等技术进行婚前筛查和咨询，以减少后代患上地贫的风险。同时，普及地贫知识，提高公众对地贫的认知和关注度，也是预防和控制地贫的重要措施之一。

血常规检查是目前筛查地贫最简单和基础的方法。由于地贫是一种遗传性疾病，因此在生育前进行地贫筛查是非常重要的。婚前筛查可以帮助夫妻了解彼此的地贫状况，从而做好家庭计划和婚姻生活的安排。孕前筛查可以预防地贫基因在后代中的传承，降低新生儿地贫的患病风险。产前筛查可以及时发现新生儿地贫，并采取有效措施进行治疗和干预。夫妻双方同时进行地贫筛查可以最大程度地避免漏诊的情况发生，确保整个家庭的健康和幸福。

近年来，国家层面对于地贫筛查防治的支持不断加强。2022年4月27日，国务院《“十四五”国民健康规划》提出到2025年，孕前优生健康检查目标人群覆盖率不低于80%，产前筛查率不低于75%，新生儿遗传代谢性疾病筛查率达到98%以上；其中亦强调强化地中海贫血等重点疾病防治。

《2021-2027 年中国婚检行业市场运行格局及战略咨询研究报告》显示: 2018 年中国婚前检查应查人数及实查人数分别为 1685.09万人、1019.60万人;2019 年中国婚前检查应查人数及实查人数分别为1542.05万人、953.25万人。地中海贫血的检查费用大概是在500到1000元左右。按照1000万人次需求来测算，每年的市场规模有望达到50亿以上。
**2、贝康创新产品打破地贫“魔咒”**
国内辅助生殖领域医疗器械创新公司——贝康医疗自主研发的胚胎植入前地中海贫血检测试剂盒（PGT-M）获得首个国家注册检定批准，开展国内针对地中海家庭阻断患儿的临床试验，可用于在胚胎植入前检测，选择不携带地中海基因突变位点的胚胎进行植入，从而让地贫患者家庭生育健康的孩子。

据悉，目前，由广州医科大学附属第三医院、海南医学院第一附属医院、柳州市妇幼保健院牵头的胚胎植入前地中海贫血检测试剂盒的临床试验招募正在进行中。

在“世界地贫日”当天，广州医科大学附属第三医院、海南医学院第一附属医院和柳州市妇幼保健院积极响应国家卫建委号召，踊跃开展线上科普直播或线下义诊活动。在贝康医疗参与的线上直播《关爱地贫，携手同行》中，广州医科大学附属第三医院和柳州市妇幼保健院为大家科普地贫的相关知识，并呼吁公众重视地贫的早筛，阻断地贫出生缺陷。目前，直播已结束，可以通过。

贝康打造的这款国产试剂盒堪称是科技创新造福百姓生育健康的一个典范。以前地贫患者因担心遗传而不敢生育，现有通过孕前一级预防的胚胎植入前筛查技术，可以精准有效的帮助患者生育健康的宝宝，并且其家族将再没有携带地中海致病基因，保障家族后代的健康。

目前贝康已经与各大生殖中心、妇幼保健院建立了合作关系。随着该核心产品的出炉，有望持续快速放量更大比重地占据国内PGT市场。

作为国内辅助生殖IVD头部企业，贝康医疗所开发的地中海贫血基因检测新技术具有准确率高、低成本等优势，为全球的地中海贫血防控提供了一种新的技术方案。未来这一产品的出炉，有望实现更精准、简便地检测胎儿的基因型，对地中海贫血的预防治疗具有长远意义。
