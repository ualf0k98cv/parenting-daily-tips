# 2026年1月1日“庆元旦·护成长”生长发育科普及义诊通知

> 更新时间：2026-09-16 (UTC+8)

**庆元旦**

**护成长**

为迎接新年的到来，关爱儿童健康成长，我院特举办“庆元旦·护成长”生长发育科普及义诊活动，为广大儿童和青少年提供专业、全面的生长发育、行为发育评估与指导，助力孩子在新的一年里“长高、长壮、长健康”。

本次活动特邀儿科、儿童保健、内分泌生长发育等多学科专业人员组成科普义诊团队，针对身材矮小、体重超标或过低、性早熟、发育迟缓、营养不良、学习困难、行为异常、智力落后及内分泌疾病等问题，提供一对一咨询与评估。活动现场将为孩子进行身高体重测量、生长发育评估、骨龄检测、营养与运动指导、多动症及自闭症量表筛查、抽动耶鲁氏量表等多项服务，帮助家长全面了解孩子的生长发育情况，及早发现潜在问题，制定个性化的干预方案。

近年来，儿童生长发育、行为发育问题日益受到社会关注。身高不达标、性早熟、肥胖、多动症、抽动症及社交问题等问题不仅影响孩子的身体健康，还可能对心理和社交造成不良影响。通过本次科普活动，我们希望帮助家长树立科学的育儿观念，掌握正确的营养、运动和睡眠知识，为孩子的健康成长打下坚实基础。

**义诊信息**

活动时间：2026年1月1日（元旦）8:00—12:00

活动地点：北海市人民医院（和平院区）门诊三楼儿童保健门诊部

参与对象：3—18岁儿童及青少年

活动内容：

1. 免费身高体重测量及生长曲线评估

2. 免费骨龄检测

3. 医生看诊

4. 营养、运动、睡眠、行为指导

5. 生长发育健康宣教资料发放

**报名方式**

欢迎广大家长携带孩子前来参加，无需挂号，名额有限（仅70名），建议提前电话：18177959926。或扫一扫以下二维码线上预约。
