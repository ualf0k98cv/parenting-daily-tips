# 【预防出生缺陷日】关注孕期营养— —为宝宝打造一个无“陷”的人生起点

> 更新时间：2026-09-17 (UTC+8)

2025年9月12日是第21个中国预防出生缺陷日，今年的宣传主题为：“关注孕期营养，孕育健康未来”。科学营养摄入不仅关乎宝宝的健康发育，也直接影响孕妈妈的身体状况。

**出生缺陷与营养的密切关系**

母体营养因素与出生缺陷发生密切相关。孕期叶酸缺乏是导致神经管缺陷的高危因素，而孕期碘缺乏则是导致儿童智力发育障碍的高危因素。

许多孕妇存在营养误区——吃得“好”不一定吃得“对”。曾有孕妇每天吃很多水果和肉，却在产检中仍然面临“叶酸不足、铁储备偏低”的提示。缺乏关键营养素，如叶酸、碘、铁等，会显著增加神经管畸形、先天性心脏病等出生缺陷的发生风险。

**孕期各阶段营养重点**

孕早期（1-12周）：奠基关键期

叶酸：每日400-800微克，预防神经管缺陷。

维生素B6：缓解孕吐反应。

优质蛋白质：支持胚胎发育。

食物推荐：深绿色蔬菜、豆类、坚果、瘦肉、鸡蛋。

孕中期（13-27周）：黄金发展期

钙质：每日1.5-2.0克，构建宝宝骨骼。

铁质：每日30毫克，预防贫血。

蛋白质：促进大脑发育。

食物推荐：乳制品、鱼类、红肉、豆制品、海产品。

孕晚期（28周-分娩）：冲刺准备期

继续保证钙、铁摄入，增加膳食纤维预防便秘，控制体重合理增长，保持充足水分摄入。

**关键营养素的补充建议**

1. 叶酸：缺乏可能引起胎儿脊柱裂、无脑儿等神经管畸形。建议孕前3个月到怀孕后3个月，每日补充0.4mg叶酸（遵医嘱），并多吃菠菜、豆类和动物肝脏。

2. 碘：缺碘可能影响胎儿大脑发育，导致智力受损。建议选择碘盐，并每周吃1-2次海产品（如海带、紫菜）。

3. 铁和钙：缺铁易导致孕妇贫血，影响胎儿供氧；缺钙则关系宝宝骨骼发育。可适量摄入红肉、动物血、牛奶和豆制品。

4. 锌：牛肉、鱼等动物性蛋白质较多的食物及海产品是锌的主要来源；植物性食物中荞麦、黑麦、小麦、玉米、花生仁、核桃仁等含锌量也较高。

**世界卫生组织三级预防策略**

世界卫生组织（WHO）推荐“三级预防”策略，从孕前到生后全程干预，为宝宝健康建立多重保障。

**一级预防：孕前干预——防患于未然（最有效、最经济的阶段）**

婚前/孕前健康检查：计划怀孕前3-6个月进行

补充叶酸：计划怀孕前至少3个月开始每日补充0.4毫克，持续至孕早期。可有效预防70%以上神经管缺陷。

接种疫苗：确保风疹、乙肝等疫苗已接种，预防感染致畸。

健康生活方式：戒烟戒酒（双方共同参与），避免接触放射线、化学毒物。

**二级预防：产前干预——早发现、早诊断**

定期产检：严格按医嘱完成每次检查

产前筛查：包括NT检查（11-13周+6）、唐氏筛查（15-20周）及无创DNA检测（NIPT，12周后）

产前诊断：针对高风险人群，通过系统排畸B超（20-24周）、羊膜腔穿刺（16-22周）进一步明确诊断

**三级预防：出生后干预——及时治疗与康复**

新生儿筛查：出生72小时后采集足跟血，筛查遗传代谢病

新生儿体检：及早发现先天性心脏病、听力障碍等隐藏问题

治疗与康复：专科规范治疗及长期康复训练

**给准妈妈的实用建议**

1. 少食多餐：减轻胃部压力，稳定血糖

2. 多样化饮食：每天摄入不同颜色的蔬果

3. 食品安全：避免生食、未煮熟食物

4. 适度运动：配合营养摄入，保持健康体重

5. 咨询专业人士：个性化营养方案很重要

6. 需要限制的食物：避免咖啡因摄入；避免高汞鱼类（如鲨鱼、剑鱼）；限制高糖、高脂肪食物；完全避免酒精和烟草

记住，孕期不是“吃两人份”而是“为两人吃对”。均衡多样的饮食、合理的体重增长和愉悦的心情，才是给宝宝最好的礼物！预防出生缺陷需要个人、家庭与社会共同参与。准父母通过学习与实践科学预防措施，为宝宝的健康奠定坚实基础。让我们关注孕期营养，共同孕育健康未来，为宝宝打造一个无“陷”的人生起点！
